# Money Flow Next UI Design

Дата: 2026-06-01

## Цель

Следующий шаг Mini App должен сделать ежедневное использование быстрее и понятнее:

- плановые траты должны резервировать бюджет и легко превращаться в фактический расход;
- dashboard должен показывать ключевые суммы в THB и USD;
- редактирование бюджета и валют должно уйти в Settings;
- интерфейс должен стать живее визуально, но остаться спокойным рабочим инструментом.

## Утвержденный визуальный стиль

Базовая палитра: **Warm Island**.

- Теплый светлый фон.
- Основной акцент: спокойный teal/green.
- USD-суммы: фиолетовый вторичный акцент.
- Плановые напоминания: теплый warning-блок.
- Категории получают устойчивые индивидуальные цвета.

Сумма в hero:

- `Можно тратить в день`
- `1 331 THB`
- `~$36`

USD не подписывается как `/day`, потому что дневной контекст уже задан заголовком.

## Dashboard

Dashboard остается первым экраном.

Показывает:

- safe-to-spend per day в THB и USD;
- Today / Week / Month / Free remaining;
- блок плановой оплаты, если сегодня есть due planned expense;
- топ категорий с цветными bars;
- последние расходы с цветными category markers.

Для категорий используется один и тот же цвет во всех местах: top categories, latest expenses, history, planned expenses.

## Плановые Траты

Форма добавления не показывается постоянно.

Экран показывает:

- компактный список плановых трат;
- кнопку `+ Добавить`;
- раскрываемую форму добавления/редактирования;
- действия у каждой плановой траты: `Оплачено`, `Изменить`, `Отключить`.

Кнопка `Оплачено`:

- создает обычный confirmed expense;
- использует сумму, валюту, категорию, теги и описание плановой траты;
- ставит дату оплаты на текущий момент;
- помечает эту плановую трату выполненной для текущего месяца, чтобы она больше не резервировала бюджет в этом месяце;
- в следующем месяце регулярная плановая трата снова учитывается как ожидаемая.

В день плановой траты dashboard показывает notice:

- название плановой траты;
- сумма THB / USD;
- кнопки `Оплачено`, `Позже`, `Изменить`.

`Позже` в первой версии только скрывает/откладывает визуальный notice на текущий просмотр, но не отменяет резерв бюджета.

## Settings

Settings становится третьей вкладкой.

В Settings находятся:

- месячный бюджет;
- base currency для учета;
- income/display currency для USD-отображения;
- источник курсов;
- позже: категории, теги, CSV export.

Редактирование бюджета убирается с Dashboard.

## Валюты И Курсы

Нужно хранить курс на дату каждой траты.

Для новых расходов:

- сохраняется original amount/currency;
- сохраняется amount_base;
- сохраняется converted_amounts, включая USD;
- сохраняется exchange_rate_date;
- сохраняется exchange_rate_source.

Dashboard показывает THB / USD через сохраненные значения, а не через текущий курс. Это важно, чтобы история не менялась задним числом.

Для старых расходов без USD-значений допустим временный fallback, но новая модель должна писать historical converted amount при создании/редактировании расхода.

## Дополнительные Идеи Позже

Не входят в ближайшую реализацию, но остаются в backlog:

- быстрые пресеты трат;
- расходы сегодня по категориям;
- дневной лимит со статусами;
- дорогая трата дня/недели;
- удобные фильтры по тегам;
- inbox для неразобранных расходов;
- еженедельный отчет в Telegram;
- повторить прошлую трату;
- soft-delete вместо полного удаления.

## Проверка

Нужно покрыть тестами:

- planned expense payment creates real expense;
- paid planned expense no longer reserves current month;
- next month recurring planned expense reserves again;
- dashboard returns USD display totals;
- settings update budget/currencies;
- category colors are mapped deterministically by slug in frontend.
