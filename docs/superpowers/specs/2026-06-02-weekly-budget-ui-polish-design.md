# Money Flow Weekly Budget UI Polish Design

Дата: 2026-06-02

## Цель

Улучшить текущий Mini App UI без смены структуры dashboard. Пользователь хочет сохранить привычный порядок метрик, добавить контроль дня и недели через прогресс, а визуально сделать интерфейс приятнее и ближе к хорошему мобильному приложению.

## Утвержденная Структура Dashboard

Dashboard остается первым экраном.

Верхний hero:

- показывает `Можно еще сегодня`;
- сумма должна совпадать с остатком в карточке `Сегодня`;
- подпись говорит, что сумма считается после бюджета и обязательных трат.

Сетка метрик остается в две колонки:

- `Сегодня` / `Неделя`;
- `Осталось` / `Месяц`.

Карточка `Сегодня` показывает:

- `потрачено сегодня / дневной план`;
- `можно еще N`;
- прогресс-бар;
- процент дневного плана.

Карточка `Неделя` показывает:

- `потрачено за неделю / план недели`;
- `осталось N`;
- прогресс-бар;
- процент недельного плана.

Карточка `Осталось` продолжает показывать свободный остаток месяца после плановых трат.

Карточка `Месяц` показывает:

- `потрачено за месяц / бюджет месяца`;
- `осталось N`;
- прогресс-бар;
- процент бюджета.

Ниже остается текущий блок `План месяца` с прогнозом, отклонением от плана, дневным планом и сравнением недели.

## Недельный План

В Settings добавляется поле `План недели`.

Если поле пустое или равно нулю, недельный план считается автоматически:

- месячный бюджет делится на количество недель в текущем месяце;
- результат используется как базовый лимит недели.

Если поле заполнено, приложение использует ручной недельный план.

Недельный остаток должен учитывать обязательные плановые траты, которые еще не оплачены и попадают в текущую неделю.

## Состояния Прогресса

Для карточек `Сегодня`, `Неделя`, `Месяц` прогресс получает состояние:

- `good`: пользователь идет нормально;
- `warn`: близко к лимиту или темп выше ожидаемого;
- `danger`: лимит почти исчерпан, превышен или темп явно опасный.

Для дня достаточно простых порогов по использованному проценту:

- до 65%: `good`;
- 65-85%: `warn`;
- 85% и выше: `danger`.

Для недели и месяца состояние учитывает темп периода:

- если использованный процент не выше ожидаемого процента периода с небольшим буфером, состояние `good`;
- если использованный процент заметно выше темпа, состояние `warn`;
- если использованный процент сильно выше темпа или лимит почти исчерпан, состояние `danger`.

## Визуальный Стиль

Утвержден вариант A: теплый clean.

Направление:

- сохранить текущую теплую палитру;
- улучшить контраст и глубину через аккуратные тени, более чистые карточки и чуть богаче цвета;
- не делать dashboard темным или сильно контрастным;
- не менять приложение на новый визуальный язык.

## Реализация

Изменения затрагивают:

- расчет budget snapshot в shared package;
- хранение и обновление настройки недельного плана у пользователя;
- API dashboard payload;
- Mini App разметку, рендеринг и CSS;
- тесты расчета бюджета и настроек.

## Проверка

Нужно проверить:

- hero `Можно еще сегодня` совпадает с остатком в карточке `Сегодня`;
- день, неделя и месяц показывают `потрачено / план`, остаток, процент и прогресс;
- недельный план использует ручное значение из Settings, если оно задано;
- автоматический недельный план работает, если ручной не задан;
- недельный остаток вычитает обязательные траты текущей недели;
- прогресс-бары получают корректные состояния `good`, `warn`, `danger`;
- существующие метрики и блок `План месяца` не исчезли.
